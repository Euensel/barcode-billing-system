# Barcode Billing System
Système de facturation par code-barres basé sur le Web 

##  Description
Application web développée en PHP procédural permettant de gérer un système de facturation avec lecture de codes-barres.

##  Objectifs
- Enregistrer des produits via code-barres
- Générer des factures automatiquement
- Gérer les utilisateurs (caissier, manager, admin)
- Stocker les données sans base de données (JSON)

##  Technologies utilisées
- PHP (procédural)
- HTML / CSS / JavaScript
- JSON (stockage des données)

## Structure du projet
- config/ : configuration globale
- auth/ : gestion des connexions
- modules/ : produits, facturation, admin
- data/ : fichiers JSON
- includes/ : fonctions PHP
- assets/ : CSS & JS
